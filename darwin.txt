# macOS-only C flags — appended after cflags/base.txt for any build that
# targets darwin (darwin / darwin-amd64 / darwin-arm64 profiles).
# Toolchain assumption: mainline LLVM clang 22 (not Apple-clang).

# NOTE: -D_FORTIFY_SOURCE=2 and -D_LIBCPP_HARDENING_MODE_FAST are parked
# in labs.disabled.txt while we prioritise startup time across both
# platforms. They will be re-enabled in lock-step with the Linux
# profile once we have a perf bench that catches the per-call cost on
# the str/mem/iterator hot paths.

# Force LLD as the linker. Apple's ld64 / ld-prime is the system default,
# but mainline clang-22 with ThinLTO produces bitcode archive members that
# autoconf conftests then fail to recognize unless the linker is bitcode-
# aware in the same way lld is. ld64.lld accepts Mach-O linker flags
# below; pass them via -Wl,-foo (single-dash) — these are NOT GNU-style
# `-Wl,-z,…` options.
-fuse-ld=lld

# Mach-O linker flags — equivalent to the -z relro/now/separate-code
# bundle on ELF. Mach-O is structurally less leaky (no GOT to overwrite
# in the ELF sense, no lazy PLT after fixup chains land), so the
# hardening surface is smaller. -dead_strip (the Mach-O analogue of
# --gc-sections) is intentionally NOT here for the same reason it's
# omitted from linux.txt: stripping at every intermediate link breaks
# autoconf conftests and dependency test binaries. Apply it at the
# final link in the consuming project.
#
#   -bind_at_load          - resolve all lazy bindings at load time (analogue
#                            of `-z now`); pairs with the chained-fixups format
#                            below to harden the import table.
#   -fixup_chains          - emit the modern dyld chained-fixups format
#                            (macOS 12+ / dyld 4+). Smaller LINKEDIT, fewer
#                            mutable mappings at load time, and the import
#                            table is no longer page-modifiable after fixup.
#   -no_data_in_code_info  - drop the LC_DATA_IN_CODE table; nothing in our
#                            translation units mixes literal data into text
#                            sections, and dropping it shrinks the binary.
-Wl,-bind_at_load
-Wl,-fixup_chains
-Wl,-no_data_in_code_info
